EXECUTIVE SUMMARY
A new spear-phishing campaign attributed to APT29 (also tracked as Cozy Bear,
The Dukes, Midnight Blizzard) was observed targeting government and diplomatic
entities across NATO member states during October-November 2024. The campaign
leveraged CVE-2024-3400 (Palo Alto Networks PAN-OS) for initial access and
deployed a custom backdoor communicating over HTTPS to actor-controlled
infrastructure.

KILL CHAIN ANALYSIS

1. Initial Access (T1566.001 - Spearphishing Attachment):
   Victims received emails impersonating NATO communications with attached
   PDF documents containing embedded JavaScript. The documents exploited a
   vulnerability in the PDF rendering engine to execute a first-stage loader.

2. Exploitation (T1190 - Exploit Public-Facing Application):
   In parallel, the actors exploited CVE-2024-3400, a command injection
   vulnerability in Palo Alto Networks PAN-OS GlobalProtect, to gain access
   to perimeter firewalls.

3. Execution (T1059.001 - PowerShell):
   The first-stage loader executed obfuscated PowerShell commands to download
   the main backdoor from the staging infrastructure.

4. Persistence (T1547.001 - Registry Run Keys):
   The backdoor established persistence via a Run key under
   HKCU\Software\Microsoft\Windows\CurrentVersion\Run pointing to a DLL
   sideloaded by a legitimate signed binary.

5. Defense Evasion (T1027 - Obfuscated Files):
   All payloads were XOR-encrypted with a rotating key. The backdoor DLL
   was sideloaded into a legitimate Microsoft process (T1574.002 - DLL
   Side-Loading).

6. Command and Control (T1071.001 - Web Protocols):
   C2 communications used HTTPS with domain fronting through legitimate
   cloud providers (Azure CDN). Beacon intervals were randomized between
   30-120 minutes.

7. Exfiltration (T1041 - Exfiltration Over C2 Channel):
   Stolen documents were compressed, encrypted, and exfiltrated over the
   existing C2 channel in chunked HTTPS POST requests.

RECOMMENDED MITIGATIONS
- Patch CVE-2024-3400 immediately on all PAN-OS devices
- Block the listed IOCs at firewall and proxy level
- Monitor for unusual PowerShell execution (Event ID 4104)
- Enable enhanced logging on all perimeter devices
- Review Run key persistence mechanisms across endpoints
- Implement DMARC/DKIM/SPF to reduce phishing delivery
- Deploy network detection rules for domain fronting patterns
